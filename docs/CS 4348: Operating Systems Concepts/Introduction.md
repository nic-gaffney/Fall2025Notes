## Operating System
- :question: What is an operating system?
    * An Operating system acts as a bridge between a user and the hardware
- :question: What is the purpose?
    - Provides an environment for a user to execute programs
- :question: What are the goals?
    - **Convinience**.
    - The secondary goal is **efficiency**
## Computer System Components
- **Hardware:** <br/>
Provides basic computing resources
    - CPU
    - Memory
    - IO
- **Operating System:**<br/>
Resource management
    - Automates resource allocation
    - Coordinates the hardware for various *Users*
- **Apps:**<br/>
Defines how the system resources are used
    - Compilers
    - Database systems
    - Video games
- **Users**<br/>
Someone or something using the computer
    - People
    - Machines
    - Other computers

## Function of Operating System
### OS as Extended machine
- Coordination and control of limited resources such as:
    - Memory
    - Disk
    - Network
    - CPU

- Deal with resource conflicts and fairness
- Make access efficient
